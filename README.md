# Ghardaia Explorer

🧭 **Discover Algeria Like Never Before!**

Ghardaia Explorer is a smart travel companion application designed to showcase the beauty, diversity, and cultural heritage of Algeria, with a special focus on the Ghardaia region. Whether you are a traveler or a local, this app provides instant access to reliable information and authentic experiences.

## 🚧 Status
**Status:** Almost Finished ⏳
*The core features are implemented. Some final minor touches and optimizations are currently being finalized.*

## ✨ Key Features
- 📍 **Wilaya Exploration**: Detailed profiles and insights into various regions.
- 🗺️ **Interactive Maps**: Guided routes to help you find must-see destinations.
- 🕌 **Heritage & Culture**: In-depth historical and architectural information.
- 🍽️ **Local Recommendations**: Hand-picked suggestions for food, accommodation, and attractions.
- 🧳 **Travel Essentials**: Tips on local customs, weather updates, and practical advice.

## 🛠️ Technical Requirements
To build and run this project locally, ensure your environment meets the following specifications:

- **JDK Version**: Java 21 (JDK 21)
  - *Note: This is required for compatibility with Gradle 8.10.2.*
- **Gradle Version**: 8.10.2
- **Android SDK**:
  - `compileSdk`: 35
  - `targetSdk`: 35
  - `minSdk`: 24 (Android 7.0+)
- **Android Studio**: Recommended version Ladybug or newer.

## 🚀 How to Download and Run

1. **Clone the Repository**
   ```bash
   git clone https://github.com/YoucefBZD/Ghardaia-Explorer.git
   ```

2. **Open in Android Studio**
   - Launch Android Studio.
   - Click on **Open** and select the project root folder.

3. **Configure the JDK**
   - Go to `File > Settings` (or `Android Studio > Settings` on macOS).
   - Navigate to `Build, Execution, Deployment > Build Tools > Gradle`.
   - Set the **Gradle JDK** to **Java 21**.

4. **Sync and Build**
   - Wait for the project to finish syncing.
   - If prompted, click **"Sync Project with Gradle Files"**.

5. **Run the Application**
   - Connect an Android device or start an Emulator.
   - Click the **Run** icon (green triangle) in the toolbar.
